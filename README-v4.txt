Установка:
1. Сделайте копию текущих файлов репозитория.
2. Замените перечисленные файлы в корне GitHub Pages.
3. Дождитесь завершения публикации GitHub Pages.
4. Откройте сайт и перезагрузите страницу. Service Worker использует новый cache temp-pro-v4.
5. В разделе резервного копирования нажмите «Выбрать папку», если браузер поддерживает эту возможность. Дайте разрешение на запись.

Что добавлено в 4.0.0:
- Новый модуль «Работа PRO»: шаблоны изделий/услуг, технологические операции, заказы.
- Снимок норм и расценок в заказе: изменения шаблона влияют только на новые заказы.
- Независимое количество для каждой операции.
- Один активный рабочий таймер; при переключении операции/раздела предыдущий ставится на паузу.
- Завершение единицы, брак на потоке, отдельное время переделки и позднее внесение брака из истории.
- Оплата за изделие, за операции или смешанная; учёт начислено/выплачено/ожидает/прогноз.
- Автоматические замеры фактического времени по завершённым единицам и предложение медианной нормы после 4 обычных замеров. Норма не меняется без подтверждения.
- Мобильная карточная форма технологической карты старого режима «Цех» вместо широкой таблицы.
- В «Цехе» время по истечении нормы больше не переводит автоматически на следующую деталь; ручное подтверждение остаётся главным.
- Полная резервная копия всех ключей приложения; при поддержке браузером — запись в выбранную папку (latest + ежедневный файл).

Ограничения текущего тестового релиза:
- Google Drive не подключён: для него нужна отдельная авторизация OAuth и настройка приложения Google Cloud.
- Автоматическая запись в папку зависит от поддержки File System Access API и разрешений браузера. Если API недоступен, используйте «Скачать копию».
- Аналитика пока базовая и агрегированная; расширенные отчёты по сменам, неделям, месяцам и трендам качества будем добавлять после тестирования.
- Не гарантируется работа таймера, если браузер полностью закрыт или Android остановил приложение в фоне.
- Проверка синтаксиса и логики выполнена локально; полноценное тестирование на HONOR Magic7 и опубликованном GitHub Pages ещё нужно провести.
