УТРЕННИЙ ТЕМП-БУДИЛЬНИК PRO+ — промежуточная сборка v10

ОСНОВА
Продолжение v9 (снимок index.html из архива v9). Существующие ключи localStorage сохранены. Перед обновлением сделайте резервную копию в приложении. Не очищайте данные сайта.

ИЗМЕНЕНИЯ v10 — ЦЕХ
- Настройка «Автозапуск следующей детали после “Готово”» теперь работает: включено — следующая деталь начинает отсчёт сразу; выключено — после завершения детали приложение ждёт отдельного нажатия на большую кнопку для запуска следующей.
- Истечение нормы остаётся только сигналом. Таймер продолжает считать фактическое время и перерасход; автозапуск следующей детали не выключается сам.
- Добавлено действие «Закончил раньше»: можно указать, на сколько минут раньше завершена текущая деталь. Замер сохраняется с пометкой приблизительной коррекции; следующая деталь не теряется.
- Кнопки управления перестроены в сетку 2×2: пауза, закончил раньше, +1 мин к норме, сброс. Основная кнопка «Готово» остаётся самой заметной.
- Сохранены предыдущие функции v9: подозрительно долгие замеры в Work PRO исключаются из статистики норм, статусы завершения заказов, сохранение ID операций шаблона.

ПРОВЕРКИ
- Встроенный JavaScript проверен Node.js --check.
- Проверены повторяющиеся HTML id: не обнаружены.
- Реальная проверка в браузере и на HONOR Magic7 не выполнялась. Это промежуточная сборка; сначала проверьте на тестовой партии.

УСТАНОВКА
1. Сделайте резервную копию данных в приложении.
2. Распакуйте архив.
3. Замените в корне GitHub Pages файлы index.html, sw.js, manifest.json, icon-192.png, icon-512.png.
4. Дождитесь публикации GitHub Pages и обновите страницу. Не очищайте localStorage и данные сайта.
