Утренний Темп-Будильник PRO+ — обновлённая сборка

Загрузите все пять файлов в корень репозитория GitHub Pages, заменив старые: index.html, sw.js, manifest.json, icon-192.png, icon-512.png.

После публикации откройте приложение и обновите страницу. Service Worker версии temp-pro-v2 удалит старый кэш и загрузит новую версию. Если на устройстве осталась старая версия, закройте установленное PWA, откройте сайт в браузере и обновите его повторно.

Важно: эта сборка улучшает восстановление состояния и поведение при возврате из фона, но веб-браузер не гарантирует выполнение таймера/JavaScript после принудительного закрытия браузера или остановки приложения системой. Для гарантированных фоновых сигналов потребуется нативный Android APK с AlarmManager/foreground service. Push-обработчик Service Worker подготовлен, но для отправки push нужен внешний сервер и подписка.
