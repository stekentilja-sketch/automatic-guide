# Утренний Темп PRO+ — v11 (этап 1: надёжность)

Основа: исходный `index.html` из архива v10. Пользовательские ключи localStorage и формат резервных копий сохранены.

## Исправления этапа 1
- Автопереход в «Цехе» больше не принудительно выключается при каждой загрузке. Для новых партий он выключен по умолчанию; настройка в партии сохраняется.
- При закрытии/сохранении партии в состоянии ожидания следующей детали не записывается фиктивное время от 1970 года.
- Отклонение от дедлайна «Утра» теперь сохраняется в секундах; старые неправдоподобные значения в миллисекундах мигрируют при запуске.
- Защита от повторного быстрого нажатия «Готово» в Work PRO; блокировка выпуска сверх планового количества обычных деталей.
- Запуск переделки явно переключает таймер в режим переделки, а не может продолжить прежний режим.
- Событие переделки синхронизируется с журналом без двойного увеличения счётчика.
- Импорт/восстановление резервной копии защищено от перезаписи восстановленного `m_work_data` обработчиком `pagehide`; добавлен откат при ошибке записи формата полной копии.
- Service Worker отдаёт сохранённую страницу сразу при наличии кэша и обновляет её в фоне.

## Проверки
- Встроенный JavaScript проверен `node --check`.
- Повторяющиеся HTML id проверены.
- Проверено отсутствие старых опасных конструкций из статического аудита в исходнике v10.
- Браузерные сценарии, восстановление на реальном устройстве и HONOR Magic7 физически не тестировались. Перед использованием на реальной партии проверьте на тестовых данных.

## Установка
1. Сначала сделайте резервную копию из приложения и сохраните файл отдельно.
2. Замените в корне GitHub Pages: `index.html`, `sw.js`, `manifest.json`, `icon-192.png`, `icon-512.png`.
3. Из архива переименуйте `index-v11.html` в `index.html`, `sw-v11.js` в `sw.js`.
4. Не очищайте данные сайта и localStorage.
