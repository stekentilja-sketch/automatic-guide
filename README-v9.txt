УТРЕННИЙ ТЕМП-БУДИЛЬНИК PRO+ — промежуточная сборка v9

ОСНОВА
Сборка продолжает исходную v7, а не резервную v8. Существующие localStorage-ключи сохранены; при замене файлов не очищайте данные сайта.

ИЗМЕНЕНИЯ v9
- Работа PRO: очень долгие замеры сохраняются в истории, но помечаются как подозрительные и не участвуют в расчёте медианы/среднего норматива. Порог пометки: больше 2 норм или больше нормы + 5 минут. Это эвристика, а не автоматическое признание ошибки.
- Работа PRO: в карточке операции отдельно показывается число обычных замеров и количество исключённых долгих замеров.
- Работа PRO: заказ получает статус «Завершён» после закрытия всех операций; карточка показывает этот статус.
- Работа PRO: при редактировании шаблона сохраняются ID операций, чтобы предложения нормативов из старых заказов продолжали находить исходную операцию шаблона.
- Версия кэша Service Worker обновлена до v9.

СОХРАНЁННЫЕ ПРАВИЛА
- +1 минута в утреннем цикле меняет только текущий проход; сама по себе не меняет шаблон.
- Изменение нормы шаблона остаётся отдельным подтверждаемым действием.
- Заказ хранит снимок операций/норм на момент создания; редактирование шаблона не переписывает состав старых заказов.
- История утренних циклов уже содержит дату, время старта/финиша, оба плана и отклонения по шагам.

ЧТО ЕЩЁ НЕ ГОТОВО
Это не полная реализация всего ТЗ. Не добавлены полноценное редактирование/удаление заказа и отдельных операций с аудит-журналом, коррекция любого замера Work PRO из истории, полный интерфейс возврата/переноса смены, гарантированное управление Bluetooth-гарнитурой при выключенном экране и облачная синхронизация. Браузерные ограничения Android/PWA остаются.

УСТАНОВКА
1. Скачайте резервную копию данных из приложения.
2. Распакуйте архив.
3. Замените в корне GitHub Pages файлы: index.html, sw.js, manifest.json, icon-192.png, icon-512.png.
4. После публикации обновите приложение. Не очищайте данные сайта и localStorage.

ПРОВЕРКИ
- Встроенный JavaScript проверен через Node.js (синтаксис).
- HTML проверен на повторяющиеся id.
- Проверка реального поведения в браузере и на HONOR Magic7 не выполнялась.
