Утренний Темп-Будильник PRO+ — сборка v6

Изменение v6: обновлён внешний вид списка «Утро». У каждой задачи есть смысловой значок (подбирается по названию), полное читаемое название, отдельная строка с приоритетом и временем, а также заметные кнопки действий с подсказками. Неизвестные названия получают значок 📌.

Установка: сделайте резервную копию данных приложения; замените в корне GitHub Pages файлы index.html, sw.js, manifest.json, icon-192.png и icon-512.png содержимым архива. Не очищайте данные сайта и localStorage. Дождитесь публикации GitHub Pages и перезапустите приложение.

Проверка: встроенный JavaScript проверен node --check. Реальный запуск в браузере и на HONOR Magic7 не выполнялся — проверьте отображение на устройстве.
